Installation

   1. Install dependencies:

    composer install
    npm install

    2. Set up environment:

    cp .env.example .env
    php artisan key:generate

    3. Configure database in .env file:

    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=db_project_management
    DB_USERNAME=root
    DB_PASSWORD=

    4. Run migrations:

    php artisan migrate

    5. Create storage link for file uploads:

    php artisan storage:link

    6. Seed the local Workspace administrator:

    php artisan db:seed

    7.  Activate Role & Permission:

    php artisan shield:setup
    php artisan shield:install
    php artisan shield:super-admin

    8. Compile assets:

    npm run dev

    9. Start the development server:

    php artisan serve

Usage

    Access the Workspace at http://localhost:8080/login
    Log in with the local Workspace credentials from your environment
    Create a new project with custom ticket prefix
    Add team members to the project
    Create and customize ticket statuses
    Add tickets and assign to team members
