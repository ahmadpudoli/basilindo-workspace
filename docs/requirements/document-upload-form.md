# Requirement: Form upload dokumen

## Tujuan

Form upload dokumen membantu pengguna memilih file, membaca preview, menulis deskripsi terformat, lalu mengisi judul dan metadata utama secara berurutan.

## Acceptance criteria

- Panel file dan deskripsi tampil berdampingan pada layar besar dan tersusun responsif pada layar kecil.
- Kontrol file dan preview tampil bersebelahan dalam panel Lampiran dengan tinggi compact yang sama.
- Tinggi area preview file dan editor deskripsi seimbang.
- Gambar menampilkan thumbnail; PDF dan format lain menampilkan ikon serta nama dan ukuran file.
- Deskripsi menggunakan Summernote yang diambil dari asset referensi lokal, tanpa CDN.
- Judul berada setelah pasangan file dan deskripsi.
- Field description tetap dikirim melalui input form yang sudah digunakan backend.
