# Halaman error Workspace

## Acceptance criteria

- Error 400, 401, 403, 404, 405, 408, 419, 422, 429, 500, 502, 503, dan 504 memiliki tampilan konsisten.
- Halaman menjelaskan masalah dengan bahasa Indonesia yang formal namun ringan.
- Tersedia tombol kembali dan dashboard/login sesuai status autentikasi.
- Animasi hanya menggunakan CSS ringan dan dinonaktifkan untuk `prefers-reduced-motion`.
- Tidak menggunakan gambar eksternal, video, atau library tambahan.
