# Requirement — Redesign beranda publik Workspace

## Tujuan

Membuat halaman `/` terasa khas Basilindo Workspace dan membantu pengunjung memahami fungsi platform sebelum masuk.

## Acceptance criteria

- Hierarki beranda jelas dan ramah; tipografi tetap selaras dengan UI Workspace.
- Palet pastel lembut, aksen warna untuk frasa penting, dan animasi halus menjaga karakter visual beranda.
- Komposisi tetap lapang dan dekorasi dashboard tidak mengganggu keterbacaan.
- Copy berbahasa Indonesia menjelaskan fungsi nyata Company, CRM, Project Management, Document Management, dan HRIS.
- Tautan navigasi, login, dan CTA mempertahankan tujuan/rute yang berjalan sekarang.
- Tampilan responsif untuk desktop, tablet, dan ponsel serta menghormati preferensi reduced motion.
- Tidak ada dependensi visual eksternal atau perubahan domain/backend.
