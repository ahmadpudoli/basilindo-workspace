# Zoom gambar pada modal preview Workspace

Semua modal yang menampilkan file gambar menyediakan kontrol zoom yang konsisten, terlepas dari modul atau jenis pengajuannya.

## Kriteria penerimaan

- Modal preview gambar menampilkan kontrol Perkecil, Perbesar, dan Sesuaikan.
- Zoom awal menyesuaikan gambar ke area viewer; pembesaran selanjutnya tetap dapat digeser di dalam viewer.
- Toolbar hanya muncul ketika konten viewer adalah gambar. PDF dan format non-gambar tidak menampilkan kontrol zoom gambar.
- Preview tetap memakai URL/endpoint dan pemeriksaan otorisasi yang sudah digunakan modal tersebut.
- Semua preview gambar menggunakan handler dan gaya toolbar bersama.
