# Layout dan aturan form perusahaan

## Acceptance criteria

- Form tambah dan edit memakai pasangan Nama–Kode, Klasifikasi–Jenis Entitas, Peran Bisnis–Terlihat pada Perusahaan Operasional, serta Parent–Status.
- Peran bisnis tidak dapat dipilih sebelum jenis entitas dan klasifikasi terisi.
- Perusahaan External tidak dapat memilih peran Perusahaan Operasional.
- Parent hanya dapat dipilih dari group aktif dengan klasifikasi yang sama.
- Aturan frontend dan backend konsisten.
