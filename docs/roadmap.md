# Roadmap Delivery

## Fase 0 — Discovery dan baseline

Requirement, role matrix, document taxonomy, data dictionary, Docker stack, dan setup docs untuk satu Workspace modular monolith.

## Fase 1 — MVP operasional

Company/project/vendor/document type, upload ke MinIO, metadata, list/detail, search filter, download satu file, role/permission, audit dasar.

## Fase 2 — Finance workflow

Document relations, PO-invoice-receipt, verification case, discrepancy, reviewer decision, status dashboard, dan notification.

## Fase 3 — Bundling dan productivity

Bulk selection, filter-based ZIP bundle, queue progress, manifest, expiry/cleanup, export metadata, saved search.

## Fase 4 — Automation

OCR, text extraction, duplicate detection, configurable matching rules, import/migration legacy files, dan integrasi email/accounting.

## Fase 5 — Group readiness

Company isolation review, centralized audit/observability, retention/legal hold, backup/restore drill, dan adapter OIDC opsional untuk integrasi eksternal.

Setiap fase harus memiliki acceptance criteria dan tidak boleh memaksa fitur fase berikutnya masuk ke MVP tanpa keputusan produk.
