# Pengelompokan pembayaran pada cetakan reimbursement

- Status pembayaran pada dokumen cetak menggunakan badge hijau untuk dibayar, kuning untuk menunggu pembayaran, dan abu-abu untuk status kosong.
- Rincian transaksi dikelompokkan dalam subbagian berjudul di dalam panel informasi pengajuan yang sama, bukan sebagai field yang bercampur dengan metadata pengajuan.
- Verifikasi: kompilasi Blade dan pemeriksaan diff whitespace.
