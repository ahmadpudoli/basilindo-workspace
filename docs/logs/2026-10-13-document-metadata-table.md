# Tabel metadata detail dokumen — 2026-10-13

## Perubahan

- Metadata pada halaman detail dokumen ditampilkan dalam tabel dua kolom.
- Nama field menggunakan format yang sama dengan form pembuatan dokumen.
- Field yang dikonfigurasi tetapi belum memiliki nilai tetap ditampilkan sebagai `Belum diisi`.
- Nilai array dan boolean ditampilkan dengan format aman.
