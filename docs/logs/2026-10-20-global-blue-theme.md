# Global blue theme

## Perubahan

- Mengubah design token primary Workspace dari merah menjadi biru.
- Menyesuaikan brand mark, tombol primary, focus state, sidebar aktif, module launcher, avatar, card modul, tabel hover, dan state dark mode.
- Warna merah dipertahankan hanya untuk konteks danger/destructive seperti tombol hapus dan konfirmasi arsip.

## Verifikasi

- `npm.cmd run build` berhasil.
- `php artisan view:cache` berhasil.
- `git diff --check` berhasil.
