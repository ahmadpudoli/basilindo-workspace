# Tampilan daftar tanggal pengajuan cuti/sakit

## Perubahan

- Kolom tabel pengajuan mengganti label `Periode` menjadi `Tanggal pengajuan`.
- Nilai tabel menampilkan seluruh tanggal detail dalam format `dd/mm/yyyy`.
- Halaman detail juga menampilkan seluruh daftar tanggal, bukan rentang tanggal
  dari kolom legacy `start_date` dan `end_date`.
