# Tooltip jenis revisi approval HRIS

## Perubahan

- Menambahkan tooltip pada label jenis revisi di popup `Minta revisi`.
- Tooltip menjelaskan perbedaan revisi substansi dan administrasi serta tahap approval yang terdampak.
- Mengaktifkan Bootstrap tooltip secara global pada elemen dengan `data-bs-toggle="tooltip"`.
