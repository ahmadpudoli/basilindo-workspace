# Konteks resource detail cuti/sakit

## Perubahan

- Link detail dari Ringkasan Cuti Karyawan menggunakan route dan controller
  khusus Ringkasan.
- Resource view detail yang sama menyembunyikan aksi pemohon pada konteks Ringkasan.
- Tombol kembali dari detail Ringkasan kembali ke halaman Ringkasan Cuti Karyawan.

## Verifikasi

- Controller, link tabel Ringkasan, dan view detail diperiksa untuk konteks halaman.
