# Ikon menu aksi daftar klaim

## Perubahan

- Mengganti ikon generik menu klaim dengan ikon lihat untuk Detail, pensil untuk Edit/Revisi, dan tempat sampah untuk Hapus.
- Memberi aksen ungu untuk edit dan merah untuk hapus agar tindakan lebih mudah dipindai.
- Memperbarui requirement dan checklist.

## Verifikasi

- Pemeriksaan diff dan `git diff --check`.
- Tidak menjalankan test suite.

## Risiko tersisa

- Tidak ada perubahan route atau perilaku aksi.
