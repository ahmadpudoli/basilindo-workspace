# Penyegaran visual Project Management

## Perubahan

- Landing page diubah menjadi konsep terang dengan gradien indigo, violet, dan amber.
- Tata letak hero dibuat asimetris: copy dan CTA di kiri, kartu weekly pulse di kanan.
- Kartu fitur menggunakan tiga aksen warna berbeda agar identitas Project Management tidak sama dengan File Organizer.
- Latar panel admin diubah menjadi gradien lembut lavender-peach dengan sidebar putih semi-transparan.

## Verifikasi

- CTA dan tautan navigasi tetap mengarah ke `/admin` dan `#fitur`.
- Layout menggunakan grid responsif untuk mobile dan desktop.
- Kontras teks pada latar terang dipertahankan menggunakan slate/indigo yang gelap.
